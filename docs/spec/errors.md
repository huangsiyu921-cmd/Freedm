# 规范性错误条件

> `DOCUMENT-CLASS: NORMATIVE`
> `BASELINE: SPEC-BASELINE-2026-10-23`
> `LEGAL-STATUS: NOT_REVIEWED / BLOCKED`
>
> 每条错误必须定义：触发条件、用户可见结果、内部状态、重试/恢复、证据。
> 未定义的行为不得以“实现细节”为由留空。

| ID | 触发条件 | 必须的处理 | 用户可见结果 | 验证 |
|---|---|---|---|---|
| ERR-DL-001 | 探测请求失败、超时或被拒绝 | 仍创建任务，总大小记为未知；下载阶段重新探测。 | 任务进入队列，显示“大小未知” | 失败服务器测试 |
| ERR-DL-002 | 续传请求得到 `200` 而非 `206` | 不得写入；按失败处理并重试；重试耗尽则任务失败。 | 任务显示失败原因，文件不被写坏 | 忽略 Range 的服务器 |
| ERR-DL-003 | 流正常结束但写入字节少于预期 | 视为短读失败，进入重试；不得标记完成。 | 任务失败/重试，不显示 100% | 截断服务器 |
| ERR-DL-004 | 单分片 3 次重试均失败 | 整个任务置 `FAILED`；取消兄弟分片；保留已写进度供后续续传。 | 错误状态与原因 | 故障注入 |
| ERR-DL-005 | `ETag`/`Last-Modified`/大小基线变化 | 丢弃旧分片计划与已下载数据，重新探测并从头下载。 | 进度归零并提示重新开始 | 变更 ETag 测试 |
| ERR-DL-006 | 任务文件被外部删除或截断 | 检测文件缺失/大小异常，重置锚点，禁止向错误偏移写入。 | 任务回到可续传/重下状态 | 删除文件测试 |
| ERR-DL-007 | 目标磁盘空间不足 | 预检失败时不启动任务；已启动时停止并保留可恢复状态。 | 明确提示空间不足 | 空间限制测试（当前 TODO） |
| ERR-DL-008 | 导出到公共目录失败 | 保留私有副本；任务仍保持完成；允许重试导出。 | 提示导出失败，文件仍可用 | 导出失败测试 |
| ERR-DL-009 | 通知权限未授予 | 下载不得因通知失败而中断；界面仍显示状态。 | 无通知，但任务正常 | 权限拒绝测试 |
| ERR-DL-010 | 网络断开或从 Wi-Fi 切到蜂窝 | 按“仅 Wi-Fi”策略转 `PAUSED` 并写等待网络标记；恢复后只拉起带标记的任务。 | 显示“等待网络” | 网络切换测试 |
| ERR-DL-011 | 删除正在运行的任务 | 取消任务协程/线程、关闭连接、删除记录与文件；不得残留“诈尸”任务。 | 列表与通知立即消失 | 运行中删除测试 |
| ERR-DL-012 | 数据库中的状态值无法反序列化 | 回退为 `FAILED`，记录诊断日志，不崩溃、不删除用户数据。 | 任务显示失败 | 脏数据注入 |
| ERR-BR-001 | 注入脚本返回值被二次编码 | 解析前必须按实际编码解码；解析失败不得静默清空列表。 | 媒体列表不丢失 | 页面测试 |
| ERR-BR-002 | 广告规则文件缺失或加载失败 | 退化为“全部放行”，不得崩溃或阻断页面。 | 页面正常加载 | 删除资源测试 |
| ERR-SH-001 | 分享内容没有可解析的 http(s) URL | 不创建任务；给出明确提示。 | 提示无有效链接 | 交互测试 |

## 错误与缺口规则

- 未实现的错误处理必须登记 `GAP-*`，不得以“当前不会发生”关闭。
- 错误条件与 `REQ-DL-*` 冲突时，以本文件为准并登记规格冲突。
- 所有错误路径必须有诊断日志，但日志不得包含完整 URL 查询参数或设备标识。
