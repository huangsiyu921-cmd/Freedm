## 1. 任务模型与状态机

| ID | 级别 | 条款 | 验证 | 来源 |
|---|---|---|---|---|
| REQ-DL-001 | MUST | 任务状态只能取 `QUEUED`、`RUNNING`、`PAUSED`、`COMPLETED`、`FAILED` 五值；不得引入 `CANCELED` 中间态。 | 枚举/DB 值检查 | CAND-DL-001 §1.1 |
| REQ-DL-002 | MUST | 删除任务时直接删除任务记录及其分片记录；删除动作不得以“取消”状态残留。 | 删除后查 DB | CAND-DL-001 §1.1 |
| REQ-DL-003 | MUST | 一个任务由一条任务记录和 N 条分片记录组成；N ≥ 1。 | DB 关系检查 | CAND-DL-001 §1.1 |
| REQ-DL-004 | MUST | 任务进入 `RUNNING` 前必须已持久化任务与分片计划。 | 崩溃注入 | CAND-DL-001 §1.1 |
| REQ-DL-005 | MUST | `COMPLETED` 仅在所有分片完成且大小校验通过后写入。 | 验收 | CAND-DL-001 §1.7 |
| REQ-DL-006 | MUST | 重启时 `RUNNING` 任务必须转为 `QUEUED` 并允许自动恢复；`PAUSED` 任务必须保持暂停。 | 重启测试 | CAND-DL-001 §1.4 |

## 2. 能力探测

| ID | 级别 | 条款 | 验证 | 来源 |
|---|---|---|---|---|
| REQ-DL-007 | MUST | 探测必须先发 `HEAD`；若被拒绝、超时或方法不支持，回退为 `GET` + `Range: bytes=0-0`。 | 服务器日志 | CAND-DL-001 §1.2 |
| REQ-DL-008 | MUST | 仅当响应表明支持字节范围且总大小已知时，任务才可标记为可分段。 | 探测结果 | CAND-DL-001 §1.2 |
| REQ-DL-009 | MUST | 必须记录 `ETag`（优先）、`Last-Modified`、`Content-Length` 作为续传校验基线。 | DB/请求头 | CAND-DL-001 §1.2 |
| REQ-DL-010 | MUST | 续传或恢复前必须复核基线；任一基线变化时不得复用已下载分片。 | 变更 ETag 测试 | CAND-DL-001 §1.2 |
| REQ-DL-011 | MUST | 探测失败不得阻止创建任务；任务以未知大小进入队列，并在下载阶段重新探测。 | 失败服务器 | CAND-DL-001 §1.2 / ERR-DL-001 |

## 3. 分片与并发写入

| ID | 级别 | 条款 | 验证 | 来源 |
|---|---|---|---|---|
| REQ-DL-012 | MUST | 默认每任务线程数为 8，允许用户设置 1–16。 | 设置/DB | CAND-DL-001 §1.3 |
| REQ-DL-013 | MUST | 默认分片粒度为 8 MiB，单任务分片数上限为 64。 | 计划检查 | CAND-DL-001 §1.3 |
| REQ-DL-014 | MUST | 当文件大小未知或小于 2 个粒度时，只使用 1 个分片。 | 计划检查 | CAND-DL-001 §1.3 |
| REQ-DL-015 | MUST | 段数按 `min(线程数, 64, floor(size/粒度))` 计算；段长按 `ceil(size/段数)` 计算，最后一段截断到总大小。 | 计划检查 | CAND-DL-001 §1.3 |
| REQ-DL-016 | MUST | 每个分片请求必须携带独立的 `Range`；分片区间必须首尾相接、无重叠、无空洞，并覆盖整个文件。 | 服务器日志 + INV-DL-004 | CAND-DL-001 §1.3 |
| REQ-DL-017 | MUST | 大小已知时，文件必须在首字节写入前预分配到最终大小。 | 文件大小检查 | CAND-DL-001 §1.3 |
| REQ-DL-018 | MUST | 多分片写入同一文件时，定位与写入必须作为一个互斥临界区执行。 | 并发测试 + 哈希 | CAND-DL-001 §1.3 |
| REQ-DL-019 | MUST | 大小未知时不得预分配，不得发送 `Range`，并使用明确的哨兵值表示未知结束位置。 | 服务器日志 | CAND-DL-001 §1.4 |

## 4. 断点续传

| ID | 级别 | 条款 | 验证 | 来源 |
|---|---|---|---|---|
| REQ-DL-020 | MUST | 每个分片必须维护独立的已写入字节计数，并作为重试与续传的唯一锚点。 | 重启测试 | CAND-DL-001 §1.4 |
| REQ-DL-021 | MUST | 分片进度落库必须满足“距上次落库 ≥1 秒或累计新增 ≥1 MiB，取先到者”。 | DB 采样 | CAND-DL-001 §1.4 |
| REQ-DL-022 | MUST | 续传请求必须要求服务器返回 `206`；若服务器以 `200` 响应且请求起点非段首，必须视为错误，不得写入。 | 忽略 Range 的服务器 | CAND-DL-001 §1.4 |
| REQ-DL-023 | MUST | 流正常结束但写入字节不足时，必须视为失败并进入重试。 | 截断服务器 | CAND-DL-001 §1.4 |
| REQ-DL-024 | MUST | 单请求最多重试 3 次，退避为 1、2、4 秒；重试必须从当前锚点继续，不得回到段首。 | 故障注入 | CAND-DL-001 §1.3/§1.4 |
| REQ-DL-025 | MUST | 续传只读取分片级已写字节，不得以任务级累计值作为续传锚点。 | 代码审查 + INV-DL-002 | CAND-DL-001 §1.4 |

| REQ-DL-028 | MUST | 任务进入终态后必须立即补位，保持并发数被填满。 | 并发测试 | CAND-DL-001 §1.5 |

## 6. 文件名与保存位置

| ID | 级别 | 条款 | 验证 | 来源 |
|---|---|---|---|---|
| REQ-DL-033 | MUST | 文件名推导顺序必须是：`Content-Disposition` 的 RFC 5987 文件名、普通 `filename`、MIME 扩展名 + URL 末段、URL 路径末段、带时间戳的兜底名。 | 单元测试 | CAND-DL-001 §1.6 |
| REQ-DL-034 | MUST | 文件名必须移除路径分隔符、控制字符与平台非法字符，并去除首尾的点与空白；空名回退为 `download`。 | 单元测试 | CAND-DL-001 §1.6 |
| REQ-DL-035 | MUST | 文件名超过 120 字符时，必须截断主名并保留扩展名。 | 单元测试 | CAND-DL-001 §1.6 |
| REQ-DL-036 | MUST | 重名时依次追加 ` (1)`…` (999)`；仍冲突时使用 `-n` 后缀。 | 单元测试 | CAND-DL-001 §1.6 |
| REQ-DL-037 | MUST | 默认保存到应用私有目录；用户可选择导出到系统公共下载目录。 | 设置/文件检查 | CAND-DL-001 §4 |
| REQ-DL-038 | SHOULD | 公共目录导出必须使用系统媒体库或等价的受支持写入方式；导出失败时保留私有副本。 | 导出测试 | CAND-DL-001 §4 / ERR-DL-008 |

|---|---|---|---|---|

| REQ-DL-044 | MUST | 前台通知必须包含进度、百分比、速度与暂停/取消动作；全部任务完成时必须发出汇总通知。 | 通知检查 | CAND-DL-001 §1.8 |
