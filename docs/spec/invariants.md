# 规范性不变量

> `DOCUMENT-CLASS: NORMATIVE`
> `BASELINE: SPEC-BASELINE-2026-10-23`
> `LEGAL-STATUS: NOT_REVIEWED / BLOCKED`
>
> 不变量必须对**所有可达状态**成立；违反任一条即为实现缺陷，登记 `GAP-*`。

| ID | 不变量 | 检查方法 | 违反后果 |
|---|---|---|---|
| INV-DL-001 | 任务级已下载总量 ≥ 所有分片已写字节之和；最多允许一个进度刷新周期的超前。 | 采样 DB：`download.downloaded >= Σ segment.downloaded`；差值不超过一个 tick 的增量。 | 进度回退、续传锚点错乱 |
| INV-DL-002 | 续传只读取分片级已写字节，从不把任务级累计值作为锚点。 | 代码审查 + 跨进程续传测试。 | 从段首重下、流量翻倍 |
| INV-DL-003 | 所有分片已写字节之和 ≤ 总大小（总大小已知时）。 | 采样 DB + 上限断言。 | 文件越界、写坏相邻数据 |
| INV-DL-004 | 一个任务的所有分片区间恰好覆盖 `[0, total-1]`，无重叠、无空洞；大小未知时只有 1 个哨兵分片。 | 分片计划静态检查 + 服务器 Range 日志。 | 文件缺失区段、哈希不一致 |

## 派生约束

- `INV-DL-001` 与 `INV-DL-002` 同时成立时，任务级值只能作为展示缓存，不能作为恢复依据。
- `INV-DL-003` 与 `REQ-DL-016` 同时成立时，最后一段必须截断到总大小。
- `INV-DL-004` 在暂停/恢复、重试、ETag 变化后都必须重新校验。
