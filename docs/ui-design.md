## 1. 导航结构

底部导航 4 项（M3 NavigationBar）：

```
[ 下载 ]   [ 浏览 ]   [ 已完成 ]   [ 设置 ]
 Downloads   Browse     Library      Settings
```

- **下载**：进行中 + 排队 + 暂停的任务
- **浏览**：内置 WebView 浏览器 + 媒体嗅探
- **已完成**：历史记录（可再次下载、可删除记录；**搜索/筛选框未实现**）
- **设置**：下载参数、外观、隐私说明

不使用侧边抽屉（1DM+ 用的抽屉+底部混合导航，此处改为纯底部导航以简化层级）。

## 2. 下载页

```
┌───────────────────────────────────┐
│ FreeDM              [🔍]  [⋮]     │  TopAppBar
├───────────────────────────────────┤
│ ┌───────────────────────────────┐ │
│ │ 📄 ubuntu-24.04.iso           │ │  文件名（2 行截断）
│ │ ████████████░░░░░░  62%       │ │  进度条
│ │ 1.2 GB / 1.9 GB · 8.4 MB/s    │ │  统计行
│ │ 剩 1 分 20 秒      [⏸] [✕]    │ │  ETA + 动作
│ └───────────────────────────────┘ │
│ ┌───────────────────────────────┐ │
│ │ …下一个任务…                   │ │
│ └───────────────────────────────┘ │
│                                   │
│              ( + )                │  FAB：添加下载
└───────────────────────────────────┘
```

- 空态：居中插画 + "还没有下载任务" + 主按钮"新建下载"。
- 每项：点击进详情；长按进入多选，可全选、暂停所选运行中任务、删除所选任务（删除需确认）。
- 顶部：两个文字按钮「全部开始 / 全部暂停」（未做 `⋮` 下拉菜单）；"仅 Wi-Fi" 开关在设置页。
- 下拉刷新不适用（本地数据，用响应式 Flow 自动更新）。

### 2.1 添加下载（ModalBottomSheet）

| 字段 | 组件 | 默认 |
|---|---|---|
| URL | OutlinedTextField（多行，自动聚焦） | 从分享/剪贴板预填 |
| 文件名 | OutlinedTextField | 自动推导后展示，可改 |
| 保存位置 | **未实现更改**，固定为应用私有目录 `files/downloads` | — |
| 线程数 | Slider 1–16 | 8 |
| 仅 Wi-Fi | Switch | 跟随全局设置 |
| | 主按钮"开始下载" | |

校验：非 http(s) 时按钮禁用并提示。

### 2.2 任务详情

显示：URL、最终 URL、保存路径、大小、已下载、分片表（索引/区间/进度）、错误信息（若有）。动作：暂停/继续/重试/删除（含删除文件开关）。

## 3. 浏览页

```
┌───────────────────────────────────┐
│ [←][→] ┌─────────────────┐ [⟳][▾2]│  地址栏 + 嗅探徽标
├───────────────────────────────────┤
│                                   │
│          WebView 内容             │
│                                   │
├───────────────────────────────────┤
│ 检测到 2 个媒体  ▸                │  底部条（有结果时才出现）
└───────────────────────────────────┘
```

- 地址栏：输入即搜索（默认搜索引擎可在设置改），或直接 URL。
- `N` 徽标：显示嗅探到的媒体数量，点击弹 BottomSheet **多选**资源列表。
- 资源列表项：Checkbox + 类型标签（VIDEO/HLS/AUDIO/FILE）+ 标题 + URL + 大小（未知则标「大小未知」）+ 来源标记。
- **多选确认**：点条目任意处切换选中；顶部有「全选 / 取消全选」与汇总行
  （`已选 N · 合计大小 [+ M 项未知大小]`）；底部「关闭」+「下载 N 项」。
  交互与边界细节见 `logic-spec.md` 第 16 部分。
- 浏览器功能范围（本版）：**前进/后退/刷新/主页 均已实现**；多标签、无痕模式、广告拦截**不做**。

> 注：以上“广告拦截不做”是早期设计；当前实现已加入域名级广告过滤，差异登记 `GAP-016`。

### 3.1 右上角 `⋮` 菜单

参考同类产品的溢出菜单，但**只放真正能用的项**（不摆死开关）。分四组，用分隔线隔开：

| 分组 | 项 | 动作 |
|---|---|---|
| 页面 | 页内查找 | 打开查找条（上一个 / 下一个 / 关闭），走 `findAllAsync` + `findNext` |
| | 查看网页源码 | `evaluateJavascript` 取 `outerHTML`，对话框内等宽字体显示，可复制 |
| | 打印页面 | `PrintManager` + `createPrintDocumentAdapter` |
| | 保存网页 | 把当前 URL 作为新下载任务（走完整探测/分片流程） |
| | 浏览历史 | 读 `copyBackForwardList()`，列表点击可跳回 |
| 嗅探 | 嗅探音频/视频 | **勾选项**，即时生效并持久化 |
| | 查看检测到的媒体 (N) | 打开媒体列表 |
| 链接 | 复制链接 / 分享链接 / 用系统浏览器打开 | 当前地址，地址为空时禁用 |
| | 打开剪贴板中的链接 | 取剪贴板里第一个 http(s) URL 直接导航 |
| 视图 | 切换到桌面版 / 移动版 | 换 UA 并重载，持久化 |
| | 清除浏览数据 | Cookie + 本地存储 + 历史 + 缓存 + 表单，并回到起始页 |

**不做**（能力不存在，不列）：新建标签、隐身、克隆标签页、广告拦截及白名单、扫描二维码（需相机权限，与隐私基线冲突）、Import cookies、离线网页、大声朗读、Copy all tab links。

### 3.2 状态与细节

- 起始页是 Compose 覆盖层而不是加载的 URL，所以首屏不会是白屏 WebView。
- 返回键：先走 WebView 历史 → 再回起始页 → 最后才退出。
- 页内查找条在地址栏下方，不弹出对话框。
- 桌面版/移动版切换与设置页的「桌面版页面」共用 `desktop_ua` 键。

## 4. 设置页（分组列表）

### 下载
- 最大同时下载数（1–8，默认 3）
- 每任务线程数（1–16，默认 8）
- 仅 Wi-Fi 下载（默认关）
- 全局限速（关 / 1–10 MB/s）
- 自动恢复未完成任务（默认开）
- 保存到公共下载目录（默认关）

### 浏览与嗅探
- 默认搜索引擎（DuckDuckGo / Google / Bing，点击循环切换）
- 自动嗅探（默认开）
- 桌面版页面（默认关）→ 与 `⋮` 菜单共用 `desktop_ua`
- 启用 JavaScript（默认开）→ `js_enabled`
- 记住上次页面（默认关）→ `remember_page`，开启后 `onPageFinished` 存 `last_page`，进入浏览页时恢复
- 清除浏览数据（动作行）→ Cookie + WebStorage + `last_page`

### 隐私
- 自动识别复制的链接（**默认关**）
- 「隐私说明」条目 → 独立页面

### 关于
- 版本、开源许可（Apache-2.0）、"本应用不收集任何数据"徽标

### 4.1 隐私说明页（独立路由）

列表形式逐条声明：

- ✅ 不读取设备标识（ANDROID_ID / IMEI / MAC / 序列号）
- ✅ 不读取 SIM 卡或运营商信息
- ✅ 不集成任何统计分析、崩溃上报、广告 SDK
- ✅ 不申请相机、麦克风、定位、应用使用情况权限
- ✅ 应用内唯一标识为本机随机 UUID，仅存于本地
- ✅ 除你主动发起的下载与网页浏览外，应用不联网
- ⚠️ 内置浏览器会像普通浏览器一样向你所访问的网站发出请求

## 5. 视觉

| 项 | 取值 |
|---|---|
| 主色 | M3 动态取色（Android 12+）；低版本回退 `#2F6FEB` |
| 风格 | M3 标准组件，圆角 16dp 卡片，无自定义皮肤 |
| 深色模式 | 跟随系统（不做日出日落自动切换 → 因此**不需要定位权限**） |
| 动效 | Compose 默认（AnimatedVisibility / animateFloatAsState） |
| 字体 | 系统默认，数字统计用等宽 |

> 与 1DM+ 的差异（有意为之）：不提供主题市场、不做自定义配色编辑器、不做底部弧形菜单。

## 6. 通知

| 场景 | 通知 |
|---|---|
| 单任务下载中 | 进度条 + `文件名 62% · 8.4 MB/s`，action：暂停、取消 |
| 多任务 | 汇总：`3 个任务下载中 · 总计 45%`，点击进下载页 |
| 单任务完成 | `下载完成：文件名`，点击用系统应用打开 |
| 失败 | `下载失败：文件名`，action：重试 |

渠道：`download_progress`（低优先级、无声）、`download_done`（默认优先级）。
